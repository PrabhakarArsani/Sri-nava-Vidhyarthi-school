# Sri Nava Vidhyarthi School Website

A modern, responsive school website built with HTML, CSS, and JavaScript. This website showcases the school's information, activities, curriculum, and provides a platform for communication with parents and students.

## 🌟 Features

### Design & User Experience
- **Modern & Responsive Design**: Fully responsive design that works on all devices
- **Dark Green Color Scheme**: Uses the school's brand color (#2c5aa0) throughout
- **Smooth Animations**: CSS animations and transitions for enhanced user experience
- **Mobile-First Approach**: Optimized for mobile devices with touch-friendly interface

### Pages & Content
1. **Home Page** (`index.html`)
   - Announcement scroll bar with important updates
   - Hero section with call-to-action buttons
   - Features highlighting school strengths
   - Leadership section with Chairman and Principal photos
   - Activities showcase

2. **About Page** (`about.html`)
   - School history and mission
   - Core values
   - Leadership team with photos and messages
   - Statistics with animated counters

3. **Gallery Page** (`gallery.html`)
   - Filterable photo gallery (Events, Activities, Sports, Cultural, Classroom)
   - Lightbox modal for image viewing
   - Recent events section
   - Interactive image overlays

4. **Curriculum Page** (`curriculum.html`)
   - Academic programs (Pre-Primary, Primary, Middle School)
   - Co-curricular activities with detailed descriptions
   - School facilities
   - Teaching methodology

5. **Contact Page** (`contact.html`)
   - Contact form with validation
   - Contact information cards
   - Interactive map
   - FAQ section
   - Social media links

### Interactive Features
- **Mobile Menu**: Hamburger menu for mobile devices
- **Gallery Filtering**: Filter images by category
- **Lightbox Gallery**: Full-screen image viewing
- **FAQ Accordion**: Expandable FAQ sections
- **Contact Form**: Form validation and submission
- **Scroll Animations**: Elements animate on scroll
- **Stats Counter**: Animated number counters
- **Smooth Scrolling**: Smooth navigation between sections

### Technical Features
- **Cross-Browser Compatible**: Works on all modern browsers
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Fast Loading**: Optimized images and code
- **Accessibility**: WCAG compliant design
- **Progressive Enhancement**: Works without JavaScript

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. **Download/Clone the files**
   ```bash
   # If using git
   git clone [repository-url]
   
   # Or download and extract the ZIP file
   ```

2. **Open the website**
   - Double-click `index.html` to open in your browser
   - Or use a local server for better development experience

3. **Using a Local Server (Recommended)**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

4. **Access the website**
   - Open your browser and go to `http://localhost:8000`
